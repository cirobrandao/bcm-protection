# BCM Protection

Lightweight anti-bot/spam protection plugin for WordPress, built for **BCM Network**.

## Features

- Honeypot field
- Timestamp validation
- Nonce validation
- Protects comments + user registrations

## Install

Copy to: `wp-content/plugins/bcm-protection/` and activate.
